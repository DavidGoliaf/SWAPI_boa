# boa-sw

Service Workers for the [Boa](https://github.com/boa-dev/boa) JavaScript engine.

This repository currently contains the **specification and work breakdown** for the
implementation. Nothing is implemented yet; start at task `T-01`.

| Document | What it is |
|---|---|
| [`TZ_boa_sw_ServiceWorkers.md`](TZ_boa_sw_ServiceWorkers.md) | The technical specification: architecture, APIs, algorithms, quality gates, and 27 work orders with acceptance criteria |
| [`AGENTS.md`](AGENTS.md) | The working contract every implementer (human or agent) follows |
| [`docs/BOA_022_PLATFORM_NOTES.md`](docs/BOA_022_PLATFORM_NOTES.md) | What Boa 0.22 provides, what it does not, and the consequences |
| [`tasks/TASK_TEMPLATE.md`](tasks/TASK_TEMPLATE.md) | Template for expanding a spec task into a work order |

Normative source: [W3C Service Workers](https://www.w3.org/TR/service-workers/).

Sibling projects in the BoaX line: `boa-idb` (IndexedDB), `boa-webstorage` (Web Storage).
